# elite102-banking-app

My project is a banking app that is terminal based that was built using Python and MySQL.

To setup the project: 
1. Set up the MySQL database according to the files
2. Update the database password
3. Run main.py

Features:
- Able to create new bank accounts with an intial balance
- Able to deposit money in accounts
- Able to withdraw money from accounts
- Can check account balances
- Can list all accounts that exist
- Exit feature
